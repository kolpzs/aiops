\section{CUSTOS (opcional)}

Esta pesquisa não demanda custos financeiros diretos significativos, uma vez que:
\begin{itemize}
    \item Os modelos de IA utilizados são de código aberto e executados localmente.
    \item A plataforma Ollama é gratuita.
    \item O Terraform é utilizado em sua versão \textit{open-source}.
    \item Os cenários de falha utilizam o provedor Docker local, sem necessidade de contas em provedores de nuvem.
    \item O hardware utilizado é o computador pessoal do pesquisador.
\end{itemize}

O único investimento relevante é o tempo computacional para execução dos experimentos, que pode ser realizado de forma autônoma durante períodos de baixa utilização do equipamento (horário noturno).
